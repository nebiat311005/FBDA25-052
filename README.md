# Eritrea Horizons

**A Digital Showcase of Eritrea’s History, Culture & Diaspora Stories**
## 🌍 About the Project

**Eritrea Horizons** is a modern, responsive educational website that celebrates the rich heritage, resilience, and identity of Eritrea. It presents the country’s history, vibrant culture, and diaspora experiences in an engaging and respectful way.

This project was developed as part of the **Web & Multimedia Development** module (Year 1, Semester 2) at Botswana Accountancy College.

---

## 🛠️ Technologies Used

- **HTML5** – Semantic markup
- **CSS3** – Custom styling with modern techniques
- **Bootstrap 5** – Responsive grid and components
- **JavaScript** – Interactive elements and form validation
- **GitHub Pages** – Hosting
- **Canva** – Image editing and logo design

---

## 📄 Pages

- **Home** – Hero section, Glimpses of Eritrea gallery, Eritrea at a Glance
- **About** – Project objectives, target audience, and future ideas
- **History** – Eritrea’s struggle and independence journey
- **Culture** – Traditions, coffee ceremony, music, languages, and identity
- **Archive** – Diaspora stories and visual gallery
- **Feedback** – Contact form with validation

---

## 🚀 Features

- Fully responsive design (mobile + desktop)
- Smooth scrolling navigation
- Interactive hover effects and gallery
- Professional branding with custom logo
- Clean, consistent layout across all pages
- Form validation (HTML5 + JavaScript)
- High-quality images with proper `alt` text
